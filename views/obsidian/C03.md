# C03

Status: accepted

The initial proposal used an orchestrator and state machine. Govi reframed the sandbox as a capability an agent uses on behalf of the human, like a calculator. The playbook records available actions and when they apply. The agent chooses actions from the current state. The runner carries out bounded operations and saves results. Govi controls scope and changes to acceptance criteria.

The long-term visualizer is an editable design-and-try workspace. Human and agent can inspect or change the same assembly, run scenarios and compare traces. A future device panel or mobile app communicates with the simulator through commands, state, and events. The Stage Zero proposal uses the existing simulator/harness, a local runner, one saved baseline and a five-second variation. The editable visualizer and panel are later proof points.
